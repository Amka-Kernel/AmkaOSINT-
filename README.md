# AmkaOSINT-

AmkaOSINT- is a lightweight, interactive terminal-based Open Source Intelligence tool built in python.

## Installation

```bash
git clone [https://github.com/Amka-Kernel/AmkaOSINT-.git](https://github.com/Amka-Kernel/AmkaOSINT-.git)
cd AmkaOSINT-
pip install requests dnspython phonenumbers
python AmkaOSINT-.py
